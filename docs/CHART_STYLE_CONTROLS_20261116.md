# 图表切换菜单统一（2026-11-16）

仅更新独立演示站。版本：`7cc61dcc-1d7e-422a-bb33-5e5fe95c404f`。

## 变更

参照 BOSS 首页浅色分段菜单：浅灰底、白色选中项、深色选中文字，未选中项灰字。桌面按钮高40px，手机44px，提供键盘焦点与高对比度状态。沿用原有图表偏好记忆及折线／柱状切换逻辑。

原因是原组件使用 `bt-style`，样式由各分析页面和 BOSS CSS 间接定义，财务独立访问时落回全局深色按钮。新 `chart-style-control.css` 由共享组件直接引入，使用独立类名，避免页面加载顺序造成差异。

共享组件调用点已检查：财务首页、BOSS首页、经营趋势、直播间近7日、投流分析、多账号趋势、加粉分析、客服考核、本组业绩、拍剪数据。拍剪填报工作台没有图表切换入口，不额外增加。
