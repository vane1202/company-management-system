# BOSS 直播间经营看板

2026-11-11，用户确认先改独立演示站，Windows 本地安装后台不更新。

## 信息层级

1. 顶部汇总：开单营业额、有效开单笔数、客户收款、已登记业务费用。日期筛选仍提供今日、本周、本月、自定义区间。
2. 直播间表现：直播间与主播、开单营业额、有效开单、付款进展、业务费用合计。桌面双列、手机单列、宽屏三列。未归属记录单列在最后，不推测其所属直播间。
3. 订单跟进：未收款／部分收款订单，可筛选直播间和付款状态；可切换本期开单，查看已结清和待核对记录。点击订单进入原档案，返回保留筛选。
4. 每间的「成本与收益」默认收起，保留料子本钱、成本来源、人员费用、提成、演员按次费用和原口径毛利。更多经营记录保留售后、全公司广告、财务核定和公司到账，不削减 BOSS 原有只读权限。

## 统计边界

- 营业额、有效开单仍归属开单日，只计原料价和代购费，跑单及退款标记源单排除。后续追加收费另列。
- 客户收款按付款日和原币分别汇总，包含历史订单收款；不能与本期开单营业额相减推算欠款。
- 付款进展的分母为本期开出的有效订单，按所选结束日之前登记的同单有效付款判断。原始约定应收加截止日内有效追加应收，与约定币种抵扣额相比较；无款为未收款、有款未足额为部分收款、已足额为已结清。第三方手续费、结汇与人民币到账不改变客户结清状态。
- 待跟进包含截至结束日的所有有效待付订单，包括历史开单，不受所选开始日截断；与当期开单进度的范围不同。没有约定付款日期，不判定逾期。缺失应收、抵扣资料或旧简版归为待核对，不冒充未付款。
- 结束日之后的付款、追加收费以及已作废行不提前计入；按当前保留的有效记录重算，不宣称提供完整历史版本快照。
- 业务费用按费用发生日汇总供货、加工、配货、配件、证书、包装、运费等，财务实际付款另列；人员费用仍在成本与收益单列。费用合计、料本与人员费用不得简单相加再扣一次。原直播间毛利仍不是公司净利润。
- 广告消耗保持全公司口径，不根据人设推测归属直播间。直播间与引流人设不设固定搭配。
