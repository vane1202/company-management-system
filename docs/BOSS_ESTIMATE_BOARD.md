# BOSS 经营估算

2026-11-11，只改独立演示站。Windows 本地安装后台仍使用原来的经营估算。

## 展示顺序

1. 开单营业额：料价加代购费，按开单日，跑单从原日扣回。
2. 客户已付款：按付款日参考汇率统一折算为人民币主数，原币金额默认收起、可展开查看。客户付给公司或第三方均计入，不代表公司已到账；与「收款与到账」页共用展示组件和折算逻辑。
3. 已看到的花费：业务费用用人民币；广告消耗以参考折算人民币为主数，美元原额作为小备注，两项继续分行展示。
4. 业务费用、广告消耗、人员成本分别进入直播间经营、推广汇总、工资汇总。
5. 原估算明细默认收起，保留订单金额、退款、历史推广费、工资分摊、定制成本、工费、运费和旧口径余额。

开单、收款和花费的日期不同，付款与广告参考折算不用于计算公司利润。工资、提成、代收手续费和结汇差额也不从开单营业额里扣。加粉和拍剪仍在各自汇总页。正式构建不包含这个演示看板。

## 2026-11-12 广告参考折算（已发布）

- 开单营业额删除金额下方重复备注，完整说明保留在提示图标。
- 今日通过 Exchangerate.dev 匿名接口读取 USD/CNY 最新行情；页面打开时每小时检查一次，重新显示页面时检查缓存是否到期。免费行情约延迟15分钟，不宣称逐秒实时。保留来源及行情时间（UTC+8），页面可见来源链接遵循免费展示要求。
- 历史消耗按对应日期的已发布参考汇率折算，不套用当前汇率。周末/节假日仅采用服务明确返回的上一发布日，并保留来源日期。每天先合计美元，用六位汇率和整数分四舍五入到人民币分，再累计区间金额。
- 最新汇率缓存一小时；历史汇率按日期缓存到本浏览器，后续最新行情不改写它。纯静态演示没有公共数据库，清除浏览器缓存/换设备会重新读取该历史日期的来源数据；这不是财务锁账，跨设备永久锁定需正式服务存储。
- 匿名历史接口目前覆盖最近30天；超范围且本浏览器没有缓存时显示「待折算」。任一天缺汇率或原消耗明细不完整，整项人民币显示待折算，美元仍保留，不用部分数据冒充总额。零消耗可直接显示零。
- 今日更新失败保留最近成功数据并提示延迟，首次失败则显示待折算。失败请求冷却一分钟，8秒超时，并发同一日期合并请求。请求仅包含币种、日期，不传业务金额、账号、客户信息、密钥或站点来源。
- 汇率只用于经营参考；实际扣款、付款、结汇及到账仍由财务独立登记。本轮不改变客户付款或其他页面的计算。
