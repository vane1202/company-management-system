# BOSS 趋势图（独立演示站）

## 页面与交互

经营估算首页保留原有关键数字，在其下新增独立「经营趋势」区。首轮提供开单与收款变化、直播间业绩对比、广告与业务费用变化共五个图表。所有图表默认折线，可统一切换柱状图；偏好仅在浏览器本地保存，未保存任何业务内容。切换类型不触发重新取数、不改日期与范围。

趋势区提供近7天、近30天、本月、自定义（1至31天），日期范围独立于原有顶部统计且明确标注。可选择直播间；广告始终是全公司消耗，不按直播间推测分摊。各直播间按日期画独立序列，柱状图为日期内分组，不把直播间类别顺序连接成趋势。

点击图中日期，或使用日期明细下拉框，可查看对应日期的原始已登记明细及原币。跳往原业务页面的按钮标为「全部…」，不暗示已携带日期筛选。

## 统计与显示

- 数据直接复用 BOSS 已授权的 live-business 接口，取当前区间与上一等长区间的原始事件。首页原有指标不改。
- 开单按原开单日统计料价＋代购费，跑单、退款标记排除，追加收费不计入。
- 客户付款按付款日统计，含旧单付款；第三方结算、公司到账、供货付款不当作客户付款。
- 客户付款及广告沿用现有参考汇率客户端，分别按付款日、消耗日折算。缺汇率不显示完整人民币合计，分组原币保留。
- 业务费用按费用发生日统计已登记成本；不将财务实际付款、工资提成加入该曲线，也不从上述曲线推算利润或广告回报倍数。
- 未观察到记录的日期为 null，显示断点／无记录，不推定漏报或已填报零。明确记录零以及全部开单已冲抵时可显示零。
- 合计明确标注「已登记合计」；缺失汇率／金额异常时整体显示横线，不将部分已知金额冒充完整总额。
- 今日未结束：折线连接今日部分用虚线，柱体变淡。今日区间不显示与完整上期的增长结论，仅并列金额。过往完整日期按已登记金额给绝对差额，不显示倍数。
- 纵轴从零开始；不同图表允许独立刻度，提示查看准确金额。小额与缺记录区间不制造极端涨跌比例。
- 当前虚构订单历史仅有少数日期；图表保留真实断点，不为图形连贯补造交易。

## 验证方式

bossTrendData.test.ts 覆盖开单回冲、追加排除、付款与到账分离、按日汇率折算、直播间筛选但广告保持公司范围、明确零与无记录、断点分段、缺汇率以及日期范围校验。另回归经营估算与客户付款汇率测试。

本次 13 项测试及 TypeScript/demo 构建通过。浏览器核对折线与柱状两种形式的合计均为：开单 3170.50、客户付款参考人民币 2467.14、广告参考人民币 1435.60、业务费用 2045.00（外币金额随公共参考行情变化）。近七天开单由昨日 1400.00 与今日 1770.50 构成；按日图中点选昨日后，明细与相应日期一致。直播间二线筛选后开单 850.00、广告仍为公司 1435.60。

图表偏好刷新后保留；选择近30天后日期为 2026-10-14 至 2026-11-12，类型保持折线。390×844、768×1024、1440×900 视口检查无横向溢出，浏览器控制台无错误。截图在忽略提交的 artifacts/boss-trends/。
