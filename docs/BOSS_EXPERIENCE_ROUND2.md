## 发布包

完整目录：`artifacts/role-demo-site`。

ZIP：`artifacts/role-demo-boss-round2-20261114.zip`。ZIP 根目录直接为 `index.html`、`assets` 等。

上传时在同一个 Worker 展开高级设置，未找到处理选择 `single-page-application`，然后再部署。

生成命令：

```powershell
npm.cmd run build -w frontend -- --mode demo --outDir dist-demo
node scripts/package-role-demo.cjs --boss-p0 --service-directory artifacts/客服账号资料核对-20261113/真实客服与账号-已按确认整理.json
```

本轮不更新 Windows 本地后台，也不推送 GitHub。真实客服名册只进入发布包中的 `service-directory.js`。
