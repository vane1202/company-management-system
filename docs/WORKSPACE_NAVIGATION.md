## 页面行为

- BOSS 首页四个速览入口，以及视频素材、加粉数据完整卡片的明细入口，进入后显示“返回管理总览”。
- 订单详情显示“返回订单列表”；列表再返回首页。桌面面包屑可点击首页和订单列表层级。
- 手机采用紧凑固定返回栏，滚动时仍可操作；演示栏不会遮挡返回按钮。首页不增加返回栏。
- 管理员、主管、财务分别返回系统管理、本组工作台、财务工作台。
- 浏览器前进、后退和刷新可恢复当前模块/订单路由。直接打开明细时，返回按钮进入明确上级，不盲目退到站外。
- 在同一次登录、未刷新页面的浏览过程中，已访问页面保留筛选、搜索和组件状态，并恢复进入明细前的滚动位置。刷新后不承诺保留筛选表单。退出或换账号后不复用上一身份的页面缓存。
- 页面参数不是授权依据，菜单仍按身份及模块权限决定是否挂载；服务端权限不变。
