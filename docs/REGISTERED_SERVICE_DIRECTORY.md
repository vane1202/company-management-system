标准production构建不引用名册资产。独立演示构建后，以显式参数加入已经获用户授权展示的本地资料：

```powershell
npm.cmd run build -w frontend -- --mode demo --outDir dist-demo
node scripts/package-role-demo.cjs --boss-p0 --service-directory artifacts/客服账号资料核对-20261113/真实客服与账号-已按确认整理.json
```

数据经白名单转换成独立的 `service-directory.js`，在演示接口之前加载。源名册与生成资产位于Git忽略的artifacts目录；代码仓库仅保留打包、读取和展示逻辑。没有参数时保持原虚构名册演示。
