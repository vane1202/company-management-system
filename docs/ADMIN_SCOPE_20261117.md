# 后台管理员职责调整与功能检查

用户要求移除管理员端的客服接待账号管理，由客服主管负责。本次修改代码和本地预览，尚未发布或推送。

## 已调整

- 管理员侧栏、手机菜单、首页快捷入口和指标不再包含接待账号。
- 首页保留员工登录账号、小组、待分配主管、模块状态；主管管理范围仍由管理员授权。
- 管理员首页不再读取接待账号接口。旧的管理员 csAccounts 页面链接回落到系统管理首页。
- 正式后端拒绝管理员访问接待账号接口，包括查看、建号、改号、启停、登记码；BOSS 原有只读筛选和主管本组权限保持。
- 管理员员工列表排除 cs_service / cs_wechat 接待主体，演示名册及管理接口也不再向管理员开放。
- 主管继续维护本组 WhatsApp / Messenger、当前持有人、交接与登记码。未分配小组的主管仍不能管理任何接待账号。

| --- | --- | --- |

| 密码重置 | 未发现管理员重置入口 | 上线前补充临时密码或重置流程、强制改密、撤销旧会话和审计 |
| 管理操作日志 | 后端已有写入审计，未发现查询界面 | 增加脱敏的账号、权限、模块操作日志；不展示客户或金额载荷 |

前端全量测试、独立角色边界单元测试、前后端构建以及本地管理员/主管页面抽查。数据库集成测试夹具已按主管登记权限调整；本轮未运行独立 PostgreSQL 集成测试，不代表正式数据库和所有业务流程已验收。
