# 拍剪历史填报管理

- 演示入口：https://demo.nanzhaoarts.com/?role=editor ，或 /fill/editor。
- 版本：0da6de7a-edef-4785-9519-3df0ed9a1bc8。
- 仅独立演示站，未更新Windows本地后台、未推送GitHub。

## 功能

- 每日填报、历史填报管理两个标签。
- 沿用魏磊、尚杰、十七的预置姓名选择，历史列表及修改随当前选择隔离。
- 支持按日期、人设筛选。点击查看／修改可更正日期、人设、拍摄、剪辑、发给运营、囤量及备注。
- 修改必须说明原因，保存前核对；记录版本递增，保留操作者及修改前后快照。
- 同一拍剪师同一天只能有一份多个人设日报，重复日期要求转入历史修改，不重复新增。
- 拦截他人记录、旧版本、未来／无效日期、负数及重复人设。囤量为当日快照，不跨日期累加。
- 切换拍剪师或标签时对未保存内容提示确认。
- 新增日报也支持会话保存后进入历史列表，刷新仍可查看。

## 演示边界

- 新接口 /api/demo/editor-identity、/api/demo/editor-history 仅拍剪角色可用。
- 当前仍是姓名选择，不能视为真实员工身份鉴权。接口依据当前会话所选姓名筛选，正式服务器必须绑定独立登录身份，禁止以客户端选择替代授权。
- 历史演练样本为每位拍剪师近3天的虚构记录；修改和新增只在当前浏览器标签页sessionStorage保留，不跨设备同步，不写正式数据库，也不更改BOSS已有拍剪汇总样本。
- 正式上线需将历史版本、审计及本人修改权限放入服务端数据库接口。本次未实现或启用正式后端修改。
