# 客服换料与定金转单演示（2026-11-16）

## 范围

仅独立演示站。Windows 本地正式后台不更新，未提交／推送 GitHub。数据保存在同源、同浏览器标签页的 sessionStorage；新设备和独立浏览器会话不会共享演练数据。

入口：客服填报 → 现有客资库 → 客户档案 → 开单记录。

1. 新开单保存商品类别、料号、开单价、代购费、约定付款币种与外币应收。
2. 展开订单，登记客户定金报送（日期、金额、付款方式、凭证编号）。
3. 点击“换料／定金转单”，填写原因与新开单卡，点击“确认换料并转入定金”。
4. 原单标为“换料取消”，有效成交金额归零；原价、料号、商品明细、原收款凭证、转单日期、经办人、原因及新单编号均保留。
5. 新单保留原单编号，承接定金抵扣，不新增收款或退款流水；可登记之后的尾款报送。结清后显示“客户已付清”。
6. 主管 → 本组客资情况 → 客服 → 客户 → 查看开单与换料记录，可以只读查看两单与付款链路。

## 统计及约束

- 原单开单日的有效业绩为 0，新单按其开单日计料价与代购费；尾款不再增加营业额。有效订单数和复购标签不把换料旧单算作成交。
- 同一客户创建关联新单，转移该原单全部已分配定金；连续换料保留关联链。
- 权限限于本人负责的客户或主管负责的小组。已取消订单不能重复转单或继续报送付款。
- 跨币种、新单应收低于转入定金、已结清或已登记尾款的订单，暂交财务核对处理，不自动换汇、退款或找零。
- 新开单日期不能早于原单和已有付款日期，凭证不能重复，付款金额不得超出应收。
- 客户付款报送只是演练记录，并未自动写入财务实际到账、第三方结汇或正式订单台账。转单没有新增现金流水，因此不会增加公司到账。
- 沿用原有照片演示限制：照片仅页面预览，不上传、不持久保存。本次保留的是商品文字明细及料号；正式照片存储随服务器落地。

- 外币约定抵扣、重复转单、越权、错误日期、超收、重复凭证、连续换料及私推代购费约束测试通过。
