# 主管消费业绩演示（2026-11-12）

## 交付范围

本次为独立演示站的主管端新增「本组消费业绩」，仅 demo 模式加载组件。沿用已经按主管范围过滤的订单列表和订单详情接口，不新增数据权限，不更新本地运行服务或推送仓库。发布包交给用户手动部署。

页面包含业绩总览、客服贡献、订单档案。支持今日、昨日、本月、自定义日期，以及经办客服、接待账号、人设、直播间筛选。订单档案另有搜索与状态筛选；可进入原订单详情并通过原返回导航退回。

## 口径

- 开单营业额按开单日累加商品开单价与代购费，排除当前已跑单、退款标记订单；追加收费不计入。旧单按当前有效状态重算，非历史录入快照。
- 客户已付款按有效付款流水的实际付款日期，含历史订单尾款，分原开单／历史未分类和已关联的售后付款。公司到账、第三方结算和扣点不替代客户付款。
- 待收款为截至结束日期的有效订单约定原币应收，扣除截至当日的抵扣金额。原单与各笔售后应收分别核对。资料缺失、非法金额、超额抵扣或关联不明显示待核对，不以零充当已结清。
- 外币客户付款沿用公共参考汇率工具，按付款日折算；待收款按所选结束日期参考折算。个人、日期及币种分组四舍五入，可能有分位差异。参考人民币不改变原币欠款或财务账。
- 个人贡献使用业务记录的经办客服姓名，固定账号不随人员变化；缺姓名归「待确认归属」。演示暂以确切姓名归并，同名不同人的真实上线须补充稳定人员标识，不能靠模糊匹配。
- 所选客服贡献占比的分母是当前筛选范围营业额；零额显示横线，不计算收款／当期开单比。
- 待跟进包含未付款、尾款待收、售后待收、资料待补。未有约定付款日，不作逾期判定；不引入工资或提成规则。

## 持有人即默认经办人

客服选择接待账号后，「每日加粉」「开单记录」「售后费用」三项表单均以该账号当前持有人预填经办客服，允许手动更正或按日报原文更正。切换账号仍经确认后清空三页试填内容。历史业务不以当前持有人重新归属。

演示 API 中改用虚构的不同经办姓名，含同账号不同经办、前任人员历史欠款，未更改业务金额。
