## 发布方式与边界

在用户 Cloudflare 账号新建仅静态资产 Worker `cuiguanjia-preview`，部署版本界面显示 56157850、100% 就绪；绑定自定义域 `demo.nanzhaoarts.com`，使用平台单页应用路由。未部署本地 Express/PG 后端，未安装 cloudflared，也没有建立到本地后台的 Tunnel。

6 个静态文件来自当前前端编译产物与独立 demo/readonly-api.js。演示中的全部数据均为虚构；角色切换只是公开页面预览，不是正式身份认证或数据隔离机制。真实权限仍在本地后端执行。该演示没有数据库、持久保存、真实员工/客户记录或正式配置凭据。

上传前检查 ZIP 内容，仅包括 index.html、demo-preview.js、应用图标、编译后 JS/CSS 和 _headers；未上传环境文件、数据库、口令、后端或 node_modules。页面与静态响应带 noindex；这不提供保密访问控制。

官网根域与 www 的 CNAME 仍指向原 nanzhaoarts.pages.dev，演示单独使用 Worker 记录；本轮未操作官网路由或邮件记录。旧 cms-fictional-readonly-demo 不作本次发布目标。

初次发布因多余 `_redirects` 与 HTML 路由校验冲突失败，移除后使用平台 SPA 设置重新发布。初次使用的名称 cuiguanjia-role-demo 后来显示不可用，最终成功服务名为 cuiguanjia-preview；未删除该初次名称的资源。发布过程中未接受付费升级或修改正式系统密码。
