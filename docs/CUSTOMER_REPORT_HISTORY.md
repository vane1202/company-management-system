# 客服填报历史与主管更正

2026-11-13：独立演示站已由用户手动部署，版本 `ddf5b859-bf33-4216-a85e-361075fc8742`。本地 Windows 安装后台未更新，未提交或推送 GitHub。

## 入口

- 客服在「每日加粉」「开单记录」「售后费用」「入场登记」选择接待账号后，可切换「填写数据／历史记录」。切换时保留正在试填的表单。
- 历史列表默认最近30天，按业务日倒序，可调整日期、分页查看，明细有返回列表按钮。没有填报显示空状态。
- 客服主管侧栏新增「填报历史管理」，可按四类业务、接待账号和日期查看本组记录。
- 记录保留业务日期、接待账号、原使用人和员工编号。换人后查看历史仍显示原使用人。

## 更正范围

客服只读。主管可预览修改本组的进粉和沟通汇总、开单商品金额、售后收费与成本、入场人数和核对来源等业务字段，必须填写更正原因。每次预览记录原值、新值、版本与操作时间，可还原。

账号、业务日期、历史使用人和考核归属不能在更正表单中修改。已关联的开单人数只读，入场人数不能少于该人数。财务扣点、结算、实际付款不在本入口开放；本次未赋予主管财务修改权限。

公开演示始终不保存：修改仅留在当前页面内存，刷新后还原，不影响经营、考核汇总。接口拒绝所有写入。此版不代表正式后台已具备持久化更正能力，后续正式实施需在服务端补充本组权限、版本校验、审计记录及关联指标重算。

## 历史来源

复用现有虚构日报、订单、售后明细与入场示例。售后历史按订单与费用发生日整理，明确区分客户追加应收与公司成本，不冒充原始客服日报，也不混入供货结算。未保存的试填不会生成历史记录。缺失字段不猜测；没有商品明细的旧订单保留历史金额只读。
