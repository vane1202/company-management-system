# 财务费用报销（独立演示）

2026-11-16，按用户要求新增公司日常运营成本之外的支出、临时支出等报销记录。

## 入口与字段

- 财务工作台 → 付款与工资 → 费用报销。
- 报销人、部门／小组、费用类别、事由、人民币金额、费用发生日期、报销登记日期、票据／凭证编号、备注。
- 预设临时支出、业务垫付、差旅外出、临时采购和其他报销。
- 可关联已有订单费用，关联后不新增重复成本。

## 流程与统计

- 财务登记 → 核对确认／退回 → 实际报销付款，支持分次付款。
- 状态区分待核对、待报销、部分报销、已报销、已退回。
- 付款记录收款人、公司付款账户、付款日期、流水号、经办人与时间；核对及付款保留版本操作历史。
- 汇总随报销人／事由搜索、类别、状态和费用发生日期筛选变化，分别显示报销申请额、已核对待报销、实际已报销。日期是费用发生日期口径，非付款日流水统计。
- 新发生的独立报销保存在独立台账，不自动计入 BOSS 日常运营成本，不把已存在的成本再算一遍。
- 关联原费用的报销付款会减少其待付金额，并同步原公司应付台账；客户收款不受影响。
- 校验金额、日期、同人同凭证重复、提交幂等、版本冲突、重复流水、超额付款。付款流水与库房付款交叉查重。

## 权限、验证及边界

- 仅财务可访问报销接口，BOSS、库房、管理员、客服主管等角色不能直接读写。
- 当前仅记录凭证编号，未新增附件上传；试填存于当前浏览器会话，不跨设备共享，不作为正式账。
