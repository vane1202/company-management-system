## 口径

- 考核跟员工，不跟接待账号。账号交接只结束旧任期、开始新任期，已封存的承接和入场记录不改写。
- 开口转化率＝同一批新客户里，已明确具体需求的人数÷已正常沟通的人数。已读不回、未读、无效粉不进分母。普通回复不算明确需求，识别日报时不自动勾选。正常沟通为 0 时不计算比例。
- 无效粉只有三类：不具备中文沟通能力、明确表示误点咨询、淫秽或色情咨询。这是投放质量，不考核客服。原因留空是待补，填 0 才是没有。三类合计不能超过无效粉人数。
- 开单率只在入场客户和开单客户已经关联时计算。未关联显示「—」，不能当成 0%。同一客户同一天多块料子只算 1 人。跑单和已标退款的订单不计开单人数。
- 入场人数仍由客服端登记，按业务日归属当时的账号使用人。没有使用人时不能检查试填。公开演示不保存。

## 谁能看到什么

| 身份 | 可见内容 |
| --- | --- |
| 后台管理员 | 员工编号和账号使用期间，不含进粉、入场、开单 |
| BOSS | 全部小组的封存承接、入场和开单归属 |
| 客服主管 | 本组同上，并可在账号管理页本地预览交接 |
| 客服填报 | 只看填报归属和本账号入场示例 |
| 运营 | 只看无效粉原因，不看客服考核 |
| 财务、拍剪 | 不能查看；所有身份的写入均拒绝 |

主管在「本组客服账号管理」核对使用历史。运营工作台底部增加「无效粉原因」，不进入客服考核。BOSS 与客服主管的「客服考核」页展示开口转化率和开单率：按人数合计，可切换折线图或柱状图；未关联的开单率显示 —。
