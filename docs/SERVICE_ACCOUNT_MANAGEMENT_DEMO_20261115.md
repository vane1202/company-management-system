# 客服账号新增与人员交接

- 独立演示站：https://demo.nanzhaoarts.com/?role=cs_supervisor&page=csAccounts
- 发布版本：e0d08daf-ab0e-41c3-b00d-210bf879eddc。
- 未更新 Windows 本地后台，未推送 GitHub。

## 功能

- 客服账号管理顶部独立的“新增账号”入口，登记 WhatsApp 或 Messenger、已有/新客服、负责起始日期和备注。
- 每位客服下的“账号更换”打开人员交接页，可选择其一个或多个在用账号，指定新负责人、交接日和原因。
- 原客服全部账号交接完成后可同时标记离职；部分交接不能标记离职。
- 交接不改变平台账号号码。账号原任期结束于生效日前一天，新任期从生效日开始。没有确认的原任期起点仍留空，不虚构历史。
- 原客资、订单、业绩、考核记录保持原员工归属；阻止新负责人在接手日期前补填新增客资日报。
- 页面提供新增与交接记录，含账号、原/新负责人、日期、原因、操作人。

## 演示边界

- 专用演示接口只允许客服主管/管理员操作当前名册小组，不开放其他业务写入。
- 操作保存在本标签页浏览器会话 sessionStorage；刷新后保留，可清除演练恢复已确认名册。试填不修改发布包或正式服务器数据。
- 新增接待账号/人员资料不会创建密码登录账号。
- 客服端再次读取账号资料时会使用本会话更新后的负责人。其他设备及标签页不会同步。
- 正式上线仍需数据库任期表、服务端鉴权、持久审计记录及登录账号管理；本次仅修改演示站。
