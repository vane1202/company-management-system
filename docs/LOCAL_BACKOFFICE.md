## 后台入口

计划本地运行同一套 Express + PostgreSQL + React 应用，浏览器进入现有登录页。默认仅监听本机；实际运行地址以验收后的配置为准。目前尚未部署，本文不表示可立即打开。

Boss / 行政登录后可见「模块管理」，可启用或停用：

- 客服加粉
- 运营投放
- 拍剪日报
- 订单

保存后立即影响服务端业务写入。停用不删除历史记录，保留原只读接口和汇总、审核数据。重新启用后恢复填报。已经打开的其他浏览器可能还显示旧入口，但写入会被服务端拒绝；刷新可更新导航。

人员、角色、工资和模块配置入口不参与本次开关。助理不能配置模块、改业务、看工资或经营估算。模块开关不会赋予任何原本没有的权限。

配置多人同时修改时，旧版本保存会返回 409。先点击「重新加载」，再修改保存，避免覆盖他人设置。

## 新增页面、字段和流程

这类变化需要开发接入，不能通过开关凭空创建业务。每次按以下步骤交付：

1. 明确字段、权限、历史数据处理、审核和汇总口径。
2. 注册新业务模块（backend/src/lib/modules.ts），挂载对应路由写入守卫，并接入前端导航。
3. 新增数据库迁移，避免改动已执行迁移；同步类型、表单、审核 payload 和展示、导出与汇总。
4. 独立测试库验证升级、权限和数据兼容，再验收窄屏界面。

当前可以新增和维护源码，但不提供后台上传可执行代码或自动安装插件的能力。
