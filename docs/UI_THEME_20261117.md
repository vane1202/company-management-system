# 界面主题「墨翠」（2026-11-17）

## 做了什么

- 新增 `frontend/src/theme.css`，在 `main.tsx` 中最后加载，覆盖设计变量与通用组件样式；原有样式文件未删除。
- 侧栏及手机顶栏为深墨绿，内容区纸白，卡片、按钮、下拉框、分段切换、表格和标签页使用同一套圆角、边框与阴影。
- BOSS 首页与财务首页各自只把**第一张核心指标卡**（总业绩、公司实际到账）做成深色玉璧卡；其余页面保持安静，不再增加深色卡。
- `AnalysisChart.tsx`：桌面端使用更宽的绘图画布，图表铺满卡片；手机端保持原画布。
- 填报页（`main.role-desk`）限宽 880px 居中，调整标题间距、说明行宽及折叠框样式。
- 演示站顶部提示条（`scripts/package-role-demo.cjs`）改为浅色胶囊切换。

## 样式约定

- 颜色、圆角等用 `theme.css` 顶部的变量（`--jade`、`--frame-1`、`--r-card` 等），不要在新组件里写死色值。
- 组件规则以 `:root` 开头，以便压过按需加载的页面样式；不要用 `!important`，下拉箭头是唯一例外（部分页面用 `background` 简写会清掉它）。
- 深色卡内用重新定义 `--ink`、`--muted`、`--line` 的方式反色，不要逐个元素改色。
- 不加入入场动画；仅保留悬停、聚焦及展开的过渡，并遵守 `prefers-reduced-motion`。
