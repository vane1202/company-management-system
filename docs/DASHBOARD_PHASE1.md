# 仪表盘第一批：口径与首屏

日期：2026-11-12。基于当前工作区已有代码完成，只生成独立演示站发布包，沿用手动发布。没有更新本地正式后台、执行数据库迁移或推送仓库。

## 统计口径

| 项目 | 本次行为 |
|---|---|
| 广告消耗 | 首页、投放分类、趋势和上期使用同一个参考报价客户端；按消耗日逐日折算人民币，USD 保留小备注及原始日报。缺报价显示待核对，不沿用固定 7.2 |
| 综合咨询成本 | 人民币参考消耗总额 ÷ 总咨询量，不平均各日报成本；零咨询不计算比率 |
| 客户已付款 | 首页与直播间统一为付款日的人民币参考折算；包含旧单尾款、售后付款。客户原币付款、第三方结算、财务实际人民币到账分别保留 |
| 本组贡献 | 个人开单营业额 ÷ 本组同日期、同人设和直播间范围营业额；个人或账号筛选不缩小本组分母。历史个人业绩保留当时经办人 |
| 满7日转化率 | 承接日及其后6天全部结束才进入成熟批次；最后观察日仍属观察中。作废排除，缺日报对应明细不展示最终率 |
| 工资 | 原“实发合计”改为“工资单净额（含草稿）”，保留原核算与锁定流程 |

开单营业额仍为料价＋代购费，未付款也计入，跑单回冲原开单日；业务费用与广告不从营业额直接相减为净利润。

## 首屏

- BOSS：开单营业额、客户已付款、业务费用、广告消耗四卡。桌面一行四列，手机2×2。原币、来源和长说明收进说明区或提示。
- 首页四卡与趋势区分别标注日期，避免将今日总额和近七日总额混用。保留折线／柱状切换。
- 主管首页：四项加粉数据之后直接显示今日订单、未报账号；沟通详情默认收起。
- 主管消费业绩：默认总览先显示待跟进，再显示客服贡献。日期自定义输入默认折叠。
