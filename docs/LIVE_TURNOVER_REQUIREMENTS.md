# 直播间营业额口径 · 定稿

状态：定稿。2026-11-10（Asia/Taipei）用户确认。本文件替代此前的“待完成细节确认”版本。

## 营业额（BOSS 首页与主管首页同一口径）

- 首项指标为“当日营业额”，依据直播间开单卡记录，不以客户当日付款或公司当日到账为计入条件。
- 营业额只计开单卡的料价和代购费，按开单卡日期归属。
- 客户在次日或约定日期付款，仍计入原开单日营业额；后续收款登记为收款流水，不再次增加营业额。
- 业务日期对应开单卡日期；填报日期、客户付款日期及第三方结算日期分别保留。
- 设计、雕刻、配货等追加收费另列（“追加收费（不计营业额）”），按发生日统计，不计入营业额。（用户确认，保持现状）
- 历史“退款”标记的源单继续单列排除，不等于退款资金流水。

## 跑单

- 跨日跑单从原开单日营业额冲抵（回冲原开单日），原开单卡、已发生成本及变更轨迹保留；不生成退款资金流水，不再催收。（用户确认，保持现状）
- 只适用于未付款、未发货、无追加应收的订单；已有收款须另行处理退款。
- 可登记与撤销的人：归属客服，以及按业务日历史小组范围管辖该单的客服主管。主管只能操作所辖小组的订单，由服务端校验；BOSS、财务、后台管理员不能操作。审计记录操作人及其角色。
- 收款与跑单同时提交时只允许一种结果（锁定订单后重新读取跑单状态）。

## 主管首页

- “今日订单概况”显示“营业额”与“有效开单”，与 BOSS 首页营业额同口径：不含追加收费，扣除跑单与历史退款标记源单。主管只看本组订单。
- 主管可在订单详情的“开单状态”中登记或撤销本组订单的跑单；其他订单资料仍只读。

## 已付款业绩（财务专项核定）

- 由财务按开单日、直播间、主播录入核定金额，供主播提成参考；系统不计算提成，不从订单或收款自动生成。
- 财务更新频率用户暂未确定，2026-11-10 起先维持现状（每个开单日、直播间、主播一条有效记录，纠错先作废再重录）。
