# 开单营业额、财务核定业绩与售后业务

业务口径于2026-11-10由用户确认；2026-11-11续接完成发布核验。本文覆盖旧版将“成交＋追加收费”合并为首页业绩的描述。

## 三项独立指标

| 指标 | 来源与归属 | 说明 |
| --- | --- | --- |
| 开单营业额（首页主数） | 开单卡日期；料价＋代购费 | 未付款仍计入，次日收款不再增加营业额；追加收费不计入 |
| 已付款业绩 | 财务按开单日、直播间、主播专项核定后手工录入 | 仅提供结果录入和查看，不自动计算主播提成，不随订单变更自动改写 |
| 售后收款 | 关联售后业务的实际付款日，按原币分别汇总 | 设计、雕刻、配货等业务收费，独立于开单营业额及财务核定业绩 |

### 跑单

- 用户选择回冲原开单日，重新计算历史营业额。
- 原开单卡不删除；记录整单跑单原因、操作人、时间、原开单日与原金额，可留痕撤销误报。
- 当前整单跑单适用于无有效收款、无有效追加应收、未发货的订单。已有定金或已发货不能用此操作代替真实退款。
- 不生成退款资金流水，已经发生的成本保留。收款和跑单并发时串行核对最新状态，不能同时成功。
- 历史退款标记源单仍按原口径单列排除，不自动转换为新跑单记录。
- 最新维护版允许客服主管登记、撤销自己负责小组的跑单，按业务发生日的历史归属校验；不扩大其他订单写入权限。BOSS、后台管理员及财务不获得此操作权限。

### 售后业务成本与毛利

- 每笔追加收费作为一笔售后业务；收款、成品采购、设计加工、证书、包装、运费等成本可明确关联到同一笔业务。
- 客服记录业务与成本；财务仍登记实际付款与结算。报价与公司成本独立填写，不互相推算。
- 成本录齐后，显示业务毛利＝该笔人民币报价－累计已归属成本；未录齐显示“成本待录齐”。新增、作废成本会取消录齐标记，需要重新核对。
- 收款、成本、发货即使跨日，也按同一售后业务归集毛利。该数未分摊广告、工资等公司费用，不称作公司净利润。
- 验证用匿名样例：收费及实收600元，成品400元＋证书6元＋盒子9元＋运费30元，成本445元，业务毛利155元。真实客户称呼、照片及付款资料未导入源码或公开演示。
- 外币收款按原币显示；第三方结汇继续独立登记，不自动推算实际人民币到账。
- 未明确关联售后业务的历史收款不自动归类，显示待归类数量；不会把历史记录缺失误当售后零收入。

### 财务录入边界

- 财务录入开单日、直播间、主播、核定人民币金额与说明；每组合一条有效记录，支持幂等提交、作废重录与审计。
- 明确录入0与尚未录入不同。BOSS只读，管理员、客服和主管无此财务接口权限。
- 核定结果只按日期、直播间、主播筛选，不假装可以按人设或客服分摊。
- 财务往期报表格式、工资提成规则仍等待用户与财务复核；本次未新增提成算法，也未修改非财务资料清单。

## 首页职责

BOSS首页展示经营结果，不展示客服催报进度，也不为该进度请求全公司加粉日报列表。客服主管首页保留“本组加粉日报填报进度”、已报／应报／未报及未报账号提醒；填报0也计为已报。

主管首页营业额与BOSS采用相同口径：原开单料价＋代购费，排除跑单及历史退款标记源单，不把追加收费并入营业额。
