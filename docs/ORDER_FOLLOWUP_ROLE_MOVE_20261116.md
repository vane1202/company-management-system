# 订单跟进岗位归属调整

## 独立演示站

- BOSS 直播间经营移除订单跟进执行清单，保留客户已付款、待收款人民币参考金额与笔数、历史欠款说明及付款待核对提示。直播间付款进度仍可查看，但不提供跟进操作。查看全部订单入口移到开单明细中。
- 客服主管“本组业绩 → 业绩总览”沿用本组待收口径，新增订单跟进卡片：默认含历史未结订单，按负责客服、付款分类、客户／订单搜索；订单按编号合并显示基础欠款与售后欠款。
- 支持登记和更新跟进备注、下次联系日期，显示更新人和时间；实际收款与结清状态保持财务维护。
- 跟进接口仅允许客服主管读写当前授权账号范围的订单，校验日期、备注长度、版本冲突，保留历史版本。客户端输入不能修改订单或收款金额。
- 演示备注存于当前浏览器会话，刷新保留，关闭会话后不保证保留；不连接生产数据库。约定付款日期未有源字段，显示未登记，不推测逾期。
